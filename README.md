# CYBERPUNK APEX: 3D ARCADE 🚀🎮✨

An elite, high-performance 3D mobile arcade game built with **Three.js**, procedural Web Audio API sound synthesis, custom particle systems, and modular JavaScript. 

## ✨ Elite Features
- **Cinematic 3D Graphics**: Dynamic neon lighting, shadow mapping, background cyberpunk skyscrapers, and grid roadways.
- **Multiple Operatives**: Choose between **Vanguard**, **Titan X**, and **Shadow Blade**, each featuring distinct visual styles and abilities.
- **Procedural Audio Engine**: Zero asset loading delays! Real-time sound effects generated instantly via the Web Audio API.
- **Advanced Particle Engine**: Explosions, speed trails, and coin collection effects rendered seamlessly.
- **Mobile & Desktop Support**: Responsive touch swipe controls, on-screen touch buttons, and desktop keyboard bindings.

---

## 🚀 Instant GitHub Pages Deployment

1. Create a new repository on GitHub.
2. Upload all files (`index.html`, `style.css`, `main.js`, `player.js`, `obstacles.js`, `particles.js`, `sound.js`, and `README.md`) into your repository root.
3. Go to **Settings > Pages**, select your `main` branch and `/ (root)` folder, and click **Save**.
4. Open your live GitHub URL and enjoy the game!
